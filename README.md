# Smart Product Recommendation System

A Python for Data Science and Machine Learning project that recommends products based on category, minimum rating, maximum price, and number of recommendations.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## How to Run

Open the project folder in VS Code.

### 1. Create virtual environment
```powershell
python -m venv venv
```

### 2. Activate it
```powershell
venv\Scripts\activate
```

### 3. Install requirements
```powershell
pip install -r requirements.txt
```

### 4. Run the application
```powershell
streamlit run app.py
```

The application will open in your browser.

## Project Features
- Product dataset
- Data cleaning
- Pandas data analysis
- NumPy feature processing
- Exploratory Data Analysis
- Data visualization
- Machine-learning-based similarity
- Product recommendations
